# land-0009 — Brigade attached to a division for shell status (15.55)

- **Cases:** land:15.55, land:9.26
- **Status:** adopted
- **Profile version:** v1
- **Decided by:** rules-land, 2026-10-06
- **Owner review:** reviewed 2026-10-06 by the owner (batch review 1)

## Question
15.55 says a brigade counts as attached to a division only if the brigade HQ counter is attached, so a Commonwealth division with nine battalions and no brigade HQs is a shell in Close Assault. The designer's own note says the case is not understood. How is the division's shell test done?

## Evidence
Case 9.26: a division is a shell when 50% or less of its allowed brigade equivalents are attached. 15.55 refines what counts as attached for that count; the two Italian brigade counters (ID code m) represent the entire brigade.

## Ruling
For the shell count in Close Assault (9.26 as applied by 15.52), a brigade counts only if its HQ counter is attached to the division. Battalions attached directly to the division HQ without a brigade HQ do not count toward the brigade total. Italian brigade counters with ID code m count as full brigades. All other cases follow 9.26 unchanged.

## Rationale
Literal reading of 15.55; only affects Commonwealth divisions that have stripped their brigade HQs.

## Affected behaviour and tests
Shell determination for organizational size in Close Assault. Test: a division with nine battalions attached and no brigade HQ is a shell (counts as a brigade equivalent).
